This is the raw assets for the webdev, mostly uncompressed assets. Use the `compress_asset.sh` [file](/compress_asset.sh) to shrink its size
Recommended file format:

* `.txt` + `.gz` compression for pictures (yes, you read that right)
* `.mid` for audio

Automation script to compress all files to `.gz` in the `data` folder is still underway, perhaps after this project is completed enough to be released.
